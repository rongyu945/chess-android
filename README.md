# 国际象棋 7.2.4（离线版）

国际象棋单机游戏（人机对战 + 双人模式），离线 HTML 转安卓 APK（WebView 壳工程）。
游戏本体是**单文件 HTML**，双击即可在浏览器里玩，也可以打包成安卓 App。

## 📦 安装包

- [`apk/国际象棋-7.2.4.apk`](apk/国际象棋-7.2.4.apk) —— 安卓安装包（安卓 5.0+，ARM64）
- Release 页面的 `chess-7.2.4.apk` 是同一个文件
- 首次安装自签名 APK 需允许「未知来源」，选「仍要安装」

## ✨ 功能

### 对局
- **执棋选择**：执白 / 执黑 / 随机（滑块式切换，偏好持久化）；执黑时黑棋在下方、白方(AI)先手
- 双人模式（对面棋子自动翻转朝向）、悔棋、新对局、认输、己方胜率记分牌
- 3 档难度：简单 / 困难 / 大师
- **对局自动保存**：每步落子后存本地，关掉 App（含安卓后台杀掉）再打开自动接着下
- **安卓返回键**：设置面板、弹窗、选题列表开着时，返回键先关它们，都没有才退出

### 界面
- **精细设置面板**：长按顶部标题唤出（隐形入口）
  - 棋盘坐标开关（a–h / 1–8）
  - 深色模式（外壳偏深蓝，棋盘保留木色只整体调暗，棋子配色不变）
  - 需要提示开关、练习模式开关
- **提示按钮**：开启后在棋盘右下角出现灯泡按钮，点它用大师档替你想一步，起点画绿框、终点加绿色光晕，并给出记谱
- **走棋记录**：可折叠；每一手都可点击，点哪一手直接回溯到那一手走之前（放弃超过 5 手会先弹确认）
- 圆角矩形图标（5 套分辨率）、音效重做（落子/吃子/将军/终局四套音色）

### 练习模式（残局题库，20 题 / 5 组）
点面板上的题名可打开**选题列表**直接跳题，面板支持「上一题 / 重试 / 下一题」。

| 组 | 题目 | 步数上限 |
|---|---|---|
| 基本杀法 | 后杀单王 / 双车杀单王 / 单车杀单王 / 双象杀单王 / 马象杀单王（最难） | 24 / 10 / 30 / 40 / 45 |
| 一步杀 | 底线杀 / 皇后贴身杀 / 把王逼进角落 / 车贴底线 | 1 |
| 两步杀 | 双车阶梯 / 王后配合 / 皇后压缩空间 / 车与王的配合 / 后与车的双重威胁 | 2 |
| 三步杀 | 三步收网 / 三步压缩 | 3 |
| 兵与车兵残局 | 王兵升变·关键格 / 连兵升变 / 远方通路兵 / 车兵必胜·搭桥 | 12 / 20 / 20 / 45 |

- 达成目标（将杀 / 升变）或超出步数会弹窗结算，可重试或进入下一题
- 战术题的步数上限就是最少步数，逼你找最短杀法
- 练习模式固定人机对练：自动隐藏执色滑块、置灰「双人对战」、「认输」变成「放弃本题」，且不进对局存档
- 每道题都经过验证：战术题用将杀求解器确认「恰好 N 步杀」，残局题用引擎自对弈实跑确认可解

## 🧠 AI 与记谱

- **标准代数记谱（SAN）**：含吃子 `x`、将军 `+`、将杀 `#`，同型子争抢同一格自动消歧义（如 `Rad1`）
- **开局库**：内置 145 条经典开局线（意大利 / 西班牙 / 西西里各变例 / 法兰西 / 卡罗康 / 后翼弃兵 / 尼姆佐 / 王翼印度 / 格林菲尔德 / 英国式 / 列蒂 / 荷兰等，共 812 个局面前缀），
  AI 开局走正规变例并按主线优先抽签保留变化；偏离开局线后自动切回搜索
- **搜索**：迭代加深 + 时间管理（逐层加深，被中断就回退到上一层，绝不出现「返回空着法导致 AI 卡住」）、
  Zobrist 增量哈希、置换表存上下界、每个节点只克隆一次棋盘
- **评估**：子力 + 位置表 + 象对 / 叠兵 / 孤兵 / 通路兵 / 车占开放线 / 残局专用王表 /
  孤王驱赶（对方只剩光王时把王赶向边角，双象马象才杀得下来）
- **难度**：差异由「搜索深度 + 时间预算 + 可接受着法质量(margin)」共同决定，
  弱化方式是在「与最佳着法差距不超过 margin」的合格着法里随机挑次优，而不是靠允许 AI 走坏棋
  - 简单 2 层 / 0.5 秒 / margin35（简单档另配"送子保护"：margin 池内剔除会丢大子且无补偿的着法，靠算得浅变弱、不主动送子）、困难 4 层 / 0.9 秒 / margin20、大师 7 层 / 3 秒 / margin0
- **规则修正**：王走开再走回原位后，易位权不会被错误恢复（不会再出现非法易位）

## 🏗️ 从源码构建

需要 JDK 21 + Android SDK 34 + Gradle 8.x：

```bash
export JAVA_HOME=/opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk/Contents/Home
export ANDROID_HOME=$HOME/android-sdk
export PATH="/opt/homebrew/opt/gradle@8/bin:$JAVA_HOME/bin:$PATH"
gradle assembleRelease --no-daemon
# 产物：app/build/outputs/apk/release/app-release.apk
```

> 说明：`release.keystore` 为本地签名密钥，出于安全未纳入版本控制，构建请在本地生成同 alias 的 keystore。
