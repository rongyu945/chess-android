# 国际象棋 7.8.1（离线版）

国际象棋单机游戏（人机对战 + 双人模式）。游戏本体是**单文件 HTML**（不含任何外部资源、完全离线），
外面套一个安卓 WebView 壳工程即可打包成 App，双击 HTML 也能直接在浏览器里玩。

## 📦 安装包

- [`apk/国际象棋-7.8.1.apk`](apk/国际象棋-7.8.1.apk) —— 安卓安装包（安卓 5.0+；无原生库，各 CPU 架构通用）
- Release 页面的 `chess-7.8.1.apk` 是同一个文件
- **不申请任何权限、不联网**（v7.8.0 起已删除 INTERNET 权限），全部逻辑与资源都在包内
- 首次安装自签名 APK 需允许「未知来源」，选「仍要安装」

## ✨ 功能

### 对局
- **执棋选择**：执白 / 随机 / 执黑（滑块式切换）
- **悔棋**：简单 10 次 / 困难 7 次 / 大师 3 次；双人模式每方 3 次
- **双人模式**：面对面各看一侧，对面棋子自动翻转 180°；悔棋按钮也放在自己那侧（对方的按钮倒置显示），只有刚走完棋的一方能悔
- 新对局 / 认输 / 结束弹窗（**复盘 / 看看棋盘 / 再来一局**）
- **提示**：顶部灯泡按钮，用引擎替你算一步（提示走独立的强搜索档：7 层 / 1.5 秒预算），棋盘上画箭头
- **对局自动保存**：每一步落进本地存档，App 关掉（含安卓后台杀掉）再打开能接着下；新对局 / 认输 / 切换模式会作废存档
- **安卓返回键**：设置面板、弹窗开着时，返回键先关它们，都没有才退出

### 界面
- **精细设置面板**（右上角齿轮）：棋盘坐标 / **大号棋盘坐标** / **严格 FIDE 判和** / 深色模式 / 声音效果 / 需要提示 / 练习模式
- 作者署名：设置面板内「作者：無限進步的戎昱」
- **走棋记录**：逐手标准 SAN 记谱（`O-O` / `exd5` / `Nbd7` …），可折叠
- **复盘**：对局结束后点「复盘」，逐手评价 ✅ 好棋 / ⚠️ 疑问手 / ❌ 失误，并对失误给出「建议：<最佳着法>」；引擎超时或算不出的那一步记「⏳ 未分析」，不评级、单独计入汇总（v7.8.0 起），可再点一次复盘重试
- **可取消**：AI 思考中点「取消」直接停掉 Worker（不再空转到超时），下一次搜索自动重建
- **无障碍**：棋格可按 Tab 聚焦并用 Enter / Space 走子，状态行 `aria-live` 播报，齿轮与难度按钮热区 ≥44px，页面允许系统缩放
- **局面评估条**：实时显示当前评分
- 立体渐变棋子 + 阴影 / 滑动走子动画 / 将军辉光 / 被吃棋子栏 / 升变选择弹窗
- 双人模式下自动隐藏执色滑块

### 练习模式（20 题 / 5 组）
点设置面板里的「练习模式」开关进入；面板上有题名、目标、步数进度与「上一题 / 重试 / 下一题」，并可打开选题列表直接跳题。

| 组 | 题目（步数上限） |
| --- | --- |
| 基本杀法 | 后杀单王 (24) / 双车杀单王 (10) / 单车杀单王 (30) / 双象杀单王 (40) / 马象杀单王·最难 (60) |
| 一步杀 | 底线杀 (1) / 皇后贴身杀 (1) / 把王逼进角落 (1) / 车贴底线 (1) |
| 两步杀 | 双车阶梯 (2) / 王后配合 (2) / 皇后压缩空间 (2) / 车与王的配合 (2) / 后与车的双重威胁 (2) |
| 三步杀 | 三步收网 (3) / 三步压缩 (3) |
| 兵与车兵残局 | 王兵升变·关键格 (12) / 连兵升变 (20) / 远方通路兵 (40) / 车兵必胜·搭桥 (45) |

- 战术题的步数上限就是最短解，逼你找最短杀法
- 达成目标（将杀 / 升变）或超步即弹窗结算，可重试或进下一题；练习模式固定人机对练（自动隐藏执色滑块、不进对局存档）
- 马象杀单王是公认最难的实用残局，连引擎自战都要 161 步（本题目已放宽到 60 步上限）

### 开局库
- **145 条经典开局线**（意大利 / 西班牙 / 西西里 / 法兰西 / 卡罗康 / 后翼弃兵 / 尼姆佐 / 王翼印度 / 格林菲尔德 / 英国式 / 列蒂 / 荷兰 等）
- 由引擎**实走生成**：键与游戏内 SAN 记谱逐字一致（零手写坐标误差），共索引出 **812 个局面位置 / 944 条着法记录**，最长的一条线 20 手
- AI 命中就照书走（同一局面有多个候选时随机选一个，增加开局变化）；走完书或偏离书后自动回退常规搜索

## 🧠 AI 与规则

- **搜索**：α-β + 迭代加深 + **PVS**（主变例搜索）+ **LMR**（后期着法削减）、Aspiration Window、置换表（软水位 6 万条 / 硬上限 20 万条 + 世代号，跨步持久复用；将杀分按 ply 归一化存储，v7.8.1 起不再跨层串分）、SEE 静态交换评估（吃子着法排序）、杀手着法 + 历史启发着法排序、静态搜索（quiescence）、将军延伸、重复局面检测
- **搜索跑在 Web Worker 里**（引擎源码打包成 Blob 起 Worker），AI 思考时界面照常流畅
- **评估**：子力 + 位置价值表（PST，含王的专门终局表）、**分段评估**（按局面阶段在中局/残局两套分之间插值）、通路兵加分、兵型 / 象对 / 开放线等结构性加分
- **难度**：

  | 档位 | 最大深度 | 硬预算 | 软预算 | 可接受差距 |
  | --- | --- | --- | --- | --- |
  | 简单 | 2 层 | 0.45 秒 | 0.18 秒 | margin 35 —— 在与最佳着法差距 ≤35 分的着法里随机挑，避免机械重复 |
  | 困难 | 4 层 | 0.6 秒 | 0.3 秒 | 0（直接走最佳） |
  | 大师 | 9 层 | 2.8 秒 | 1.05 秒 | 0（直接走最佳） |

- **规则**：完整实现王车易位（含易位权失效判定）/ 吃过路兵 / 升变、逼和、子力不足判和
- **和棋按 FIDE 分层**（v7.8.0 起）：三次重复与五十步在休闲模式下自动判和；打开「严格 FIDE 判和」后按 FIDE 9.2/9.3 只能由走子方点「主张和棋」，五次重复与七十五步才自动判和。删除了旧版非 FIDE 的「连续 25 次将军判和」
- **死局判定收窄**（v7.8.0）：只认 K 对 K、K+单象/单马对 K、双方同色格单象；双马不再被误判死局
- **过路兵局面键**（v7.8.0）：只有确实合法的吃过路兵才进重复局面键，避免假重复

## 🏗️ 从源码构建

需要 JDK 21 + Android SDK 34 + Gradle 8.x：

```bash
export JAVA_HOME=/opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk/Contents/Home
export ANDROID_HOME=$HOME/android-sdk
export PATH="/opt/homebrew/opt/gradle@8/bin:$JAVA_HOME/bin:$PATH"
gradle assembleRelease --no-daemon
# 产物：app/build/outputs/apk/release/app-release.apk
```

> `release.keystore` 为本地签名密钥，出于安全未纳入版本控制；构建请自行生成同 alias 的 keystore，签名口令可写在项目根目录的 `keystore.properties`（`storePassword` / `keyAlias` / `keyPassword`，该文件同样不进版本库）。
